# Forguncy 예산 관리 데모

Forguncy(노코드 플랫폼)로 구현한 **예산 관리** 데모입니다.
부서·항목별 예산과 실제 집행 현황의 차이를 확인할 수 있는 예산 관리 업무를 노코드로 구축한 예시를 확인할 수 있습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/BudgetManage)

## 📋 주요 기능

- 부서/항목별 예산 등록
- 실제 집행(지출) 내역 입력
- 예산 대비 집행 현황(차이) 조회
- 예산 초과 여부 시각화

## 💾 Forguncy 다운로드

이 데모는 MESCIUS Forguncy로 제작되었습니다. 직접 열어보거나 커스터마이징하려면 아래에서 Forguncy를 다운로드하세요.

👉 [Forguncy 다운로드](https://www.mescius.co.kr/forguncy/download)

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 예산 대비 집행 현황처럼 수식 기반 비교·분석이 필요한 업무도 Excel 함수를 그대로 활용해 손쉽게 구축할 수 있습니다.
